# Al Fajjar Zunzo Angular

This Angular wrapper keeps the existing Zunzo HTML, CSS, JavaScript, images, and localStorage behavior intact while exposing the site through Angular routes.

## Run

```bash
npm install
npm start
```

Then open:

```text
http://127.0.0.1:4200
```

## Routes

- `#/indoor-arena` -> `index.html`
- `#/cricket-stadium` -> `homev2.html`
- `#/about` -> `about.html`
- `#/bookings` -> `event.html`
- `#/booking-details` -> `event-details.html`
- `#/teams` -> `community.html`
- `#/profile` -> `profile.html`
- `#/dashboard` -> `dashboard.html`
- `#/contact` -> `contact.html`
